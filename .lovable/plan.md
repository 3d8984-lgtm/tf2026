# QR 라벨 Master PNG 출력 파이프라인 검증 및 수정

## 목표
최종 미리보기와 T300 출력에 같은 완성 PNG를 사용하고, 생성부터 프린터 전달까지 크기·해시·용지 정보가 달라지는 지점을 확인할 수 있게 합니다. QR 좌표나 임의 보정값은 변경하지 않습니다.

## 구현 범위
1. **단일 Master PNG 생성**
   - 일반 라벨, 중앙 +, 6×6mm 사각형, QR 진단을 모두 같은 래스터 생성기로 통일합니다.
   - 최종 미리보기는 이 PNG 자체만 표시하며 QR이나 좌표를 다시 계산하지 않습니다.

2. **PNG 직접 전송과 무결성 검증**
   - PDF로 다시 감싸 보내는 현재 경로를 제거하고 Master PNG 바이너리를 Print Agent에 직접 전송합니다.
   - 브라우저에서 SHA-256, 픽셀 크기, 실제 mm, 요청 DPI를 계산해 요청에 포함하고 화면에 표시합니다.
   - 전송 직전 PNG와 다운로드 PNG가 동일한 객체임을 보장합니다.

3. **Print Agent 기능 자동 판별**
   - 실행 중인 Agent의 상태/버전/지원 기능을 조회합니다.
   - 수신 해시, 수신 픽셀 크기, 드라이버 DPI, 물리 용지, 인쇄 가능 영역, 물리 오프셋 정보를 Agent가 제공하면 화면에서 요청값과 나란히 비교합니다.
   - 구형 Agent가 해당 정보를 제공하지 않으면 ‘검증 불가’로 표시하며 일치했다고 오인하지 않습니다.

4. **RAW 1:1 Bitmap 출력**
   - 확대·축소, 맞춤, 중앙정렬, 회전, 자르기, 분할 없이 (0,0) 기준으로 보내는 진단 출력을 추가합니다.
   - Agent가 RAW PNG 출력을 지원하지 않으면 버튼을 비활성화하고 필요한 Agent 업데이트 항목을 안내합니다.

5. **진단 결과 및 실패 차단**
   - 요청 PNG와 Agent 수신 해시/픽셀 크기가 다르면 인쇄를 실패 처리합니다.
   - Requested DPI와 Driver DPI, 요청 용지와 실제/인쇄 가능 영역 차이를 경고합니다.
   - 중앙 + → 사각형 → QR이 같은 출력 함수와 전송 규격을 사용하도록 테스트합니다.

## 기술 세부사항
- 현재 웹앱에는 Print Agent 구현 소스가 없으므로 Agent가 새 PNG 계약을 지원하는지 런타임에서 판별합니다.
- 새 계약은 `image/png` 바이너리와 크기·DPI·SHA-256 헤더를 사용하고, 응답 진단값을 검사합니다.
- 기존 구형 PDF 계약은 일반 출력의 호환 경로로 유지하되, 이를 사용할 경우 ‘Master PNG 동일성 미검증’ 상태를 명시합니다. RAW 1:1 진단에서는 PDF 폴백을 사용하지 않습니다.
- 기존 X 방향 배열, QR 중심 좌표, 행 간격, 저장된 보정값은 수정하지 않습니다.

## 검증
- Master PNG 해시가 다운로드 및 전송 직전에 동일한지 자동 테스트합니다.
- 일반/+/사각형/QR의 PNG가 동일 크기·DPI·파이프라인으로 생성되는지 테스트합니다.
- 브라우저에서 최종 PNG 미리보기, 해시, Agent 기능 상태, RAW 출력 상태를 확인합니다.
- 실제 T300 출력과 드라이버 수치는 사용자의 Windows Agent가 새 계약을 지원할 때 최종 확인합니다.

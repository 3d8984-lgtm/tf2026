# QR 라벨 세로 분할 인쇄 진단 및 수정

## 목표
- 현재 정상인 5열 X 배열은 유지합니다.
- 임의 Y 보정 없이 실제 PDF 좌표, 페이지 크기, 행 피치, 렌더 개수를 확인해 세로 분할·반복 원인을 제거합니다.
- 설정 미리보기가 아니라 프린터에 전달되는 최종 PDF 자체를 확인할 수 있게 합니다.

## 작업 내용
1. **인쇄 문서 좌표계를 명시적으로 분리**
   - 라벨 높이 15mm와 세로 피치 17mm를 별도 값으로 계산합니다.
   - 각 항목에 `row`, `column`, `labelX/Y`, `qrCenter`, `qrLeft/Top`, `qrAbsoluteX/Y`를 산출하는 공통 레이아웃 함수를 만듭니다.
   - 실제 PDF 생성과 디버그 정보가 같은 계산 결과만 사용하게 하여 미리보기/인쇄 간 계산 차이를 없앱니다.

2. **PDF 페이지 및 행 생성 방식 수정**
   - 5열 한 행마다 별도 17mm PDF 페이지를 반복하는 현재 구조를 제거합니다.
   - 모든 행을 한 개의 연속 롤 문서에 `rowY = row × 17mm`로 배치하고, 문서 높이를 `행 수 × 17mm`로 생성합니다.
   - QR은 각 라벨 내부 좌표 `centerY - height/2`에서 시작해 `labelY`를 더한 절대 좌표로 한 번만 그립니다.
   - 프린터 에이전트에는 실제 PDF 전체 폭·높이를 전달하여 15×15mm 개별 페이지로 재해석되지 않게 합니다.

3. **중복·경계·클리핑 검사**
   - PDF 생성 직전에 첫 10개 항목의 요청된 모든 좌표와 문서 크기, 총 렌더 개수를 구조화된 콘솔 표로 출력합니다.
   - 각 항목은 정확히 한 번만 PDF에 추가되도록 검증하고, 중복 인덱스나 범위 밖 좌표는 인쇄 전에 오류로 중단합니다.
   - QR 인쇄 경로에는 HTML/CSS, 설정 모달, 숨은 미리보기 DOM이 섞이지 않음을 코드와 생성 PDF로 확인합니다.

4. **실제 PDF 기반 최종 인쇄 미리보기**
   - 현재 단일 라벨 미리보기와 별도로, `buildLabelsPdf`가 생성한 동일 Blob을 표시하는 최종 인쇄 미리보기를 추가합니다.
   - 최종 문서 폭/높이, 행·열·피치, 총 항목 수를 함께 표시합니다.
   - 다운로드와 실제 인쇄도 같은 PDF 생성 함수를 사용합니다.

5. **단계별 진단 출력**
   - 5열×10행, 총 50칸 고정 진단 문서를 만듭니다.
   - 1단계: 각 라벨 중심(7.5, 7.5mm)에 작은 `+`만 벡터로 출력합니다.
   - 2단계: 각 라벨 중심에 6×6mm 검은 사각형만 벡터로 출력합니다.
   - 3단계: QR만 출력합니다.
   - 각 단계는 별도 미리보기·PDF 다운로드·인쇄 버튼을 제공해 순서대로 물리 출력 결과를 비교할 수 있게 합니다.

6. **검증**
   - 15mm 원형, 간격 2mm, 5열 기준 문서 폭 83mm 및 행 Y `0, 17, 34, ...`를 자동 테스트합니다.
   - QR top Y가 `2.6, 19.6, 36.6, ...`인지 검사합니다.
   - 생성 PDF를 이미지로 변환해 모든 행의 +/사각형/QR이 한 번씩 완전히 들어가는지 시각 검수합니다.
   - 화면에서 최종 미리보기와 진단 제어가 정상 동작하는지 확인합니다.

## 기술 세부사항
- 수정 중심: QR 라벨 PDF 생성기와 QR 라벨 인쇄 패널.
- X 공식은 기존 `labelX = marginLeft + column × (labelWidth + horizontalGap)`을 유지합니다.
- Y 공식은 `labelY = marginTop + row × (labelHeight + verticalGap)`만 사용합니다.
- 인쇄용 PDF는 HTML/CSS `@page`, `overflow`, `transform`, iframe을 사용하지 않고 PDF 벡터/이미지 좌표만 사용합니다.
